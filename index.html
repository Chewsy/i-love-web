Learning Journal

01-02-2026

Ik heb geleerd hoe handing de * selector is. Met de selector wordt de CSS styling toegepast op alle children elementen van de parent element. Dit het ik toegepast op mijn I love web om de cursor in te stellen als pointer op alle folder iconen en tekst.

Ook heb ik geleerd dat user-select: none; er voor zorgt dat tekst niet te selecteren is en hierdoor "functioneert" mijn macOS bar zoals het hoort.

Bronnen:
Universal selector
user-select property
